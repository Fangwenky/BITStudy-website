    下载前，你可能想知道
    几个小问题。
    
      
    怎么安装？＋
    在 Android 手机上下载 APK 后打开，根据系统提示允许浏览器安装应用，再完成安装。BITStudy 目前不提供 iOS 版本。
    
      
    旧版本可以直接升级吗？＋
    签名一致时可以直接覆盖安装。如果系统提示签名不一致，请先保留旧应用，并通过项目 Issues 反馈，避免卸载造成课表等本地数据丢失。升级后校园账号可能需要重新登录。
    
      
    校园功能需要什么条件？＋
    延河课堂和 DDL 等功能需要有效的北京理工大学校园账号，并受相应平台访问条件影响。DDL 同步 BIT 学习平台的作业和考试，请同时留意乐学、教师通知等其他渠道。
    
      
    在哪里反馈问题或参与开发？＋
    欢迎在 GitHub Issues 提交问题或建议，也可以提交 Pull Request 参与开发。反馈时请勿附上密码、验证码或 API Key。
