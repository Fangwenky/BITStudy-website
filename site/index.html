    下载前，你可能想知道
    几个小问题。
    
      
    怎么安装？＋
    在 Android 手机上下载 APK 后打开，根据系统提示允许浏览器安装应用，再完成安装。BITStudy 目前不提供 iOS 版本。
    
      
    旧版本可以直接升级吗？＋
    签名一致时可以直接覆盖安装。如果系统提示签名不一致，请先保留旧应用，并通过项目 Issues 反馈，避免卸载造成课表等本地数据丢失。升级后校园账号可能需要重新登录。
    
      
    校园功能需要什么条件？＋
    BIT 指北京理工大学（Beijing Institute of Technology）。延河课堂和 DDL 等校园功能需要有效的北理校园账号，并受对应平台访问条件影响。DDL 当前同步 BIT 学习平台，请同时留意乐学、教师通知等其他渠道。
    
      
    BITShare 是什么？资料需要付费吗？＋
    BITShare 是北理同学自主创建的开源资料共享项目，为同学们提供免费学习资料搜索与下载。BITStudy 接入其公开资料服务，方便在应用内搜索、浏览和下载；资料内容由 BITShare 社区提供。
    
      
    在哪里反馈问题或参与开发？＋
    欢迎在 GitHub Issues 提交问题或建议，也可以提交 Pull Request 参与开发。反馈时请勿附上密码、验证码或 API Key。
